# E1 엔진 격리 설계 메모

기준: ADR-0004, 2026-11-04. 운영 상태와 타이머는 변경하지 않는다.

- ADR 927~953행: `--bare`와 워크플로우/MCP의 호환성은 미확인이다. 비어 있는 임시 `HOME`·`CLAUDE_CONFIG_DIR`와 API 키 도우미를 사용한다(독립 검토 뒤 수정 절 참조). 실행 전 `auth status`, 실행 중 `system/init.apiKeySource`를 모두 확인한다. 불일치와 서명 누락은 해당 API 엔진만 끄고 사고를 남긴다. 상태 조회는 유료 카나리아가 아니다.
- ADR 1067~1072행, 1095행: 초과 사용 신호의 “정지”는 수동 구독 실행 하나의 중단이다. API 엔진이나 영구 `llm:off:*`를 쓰는 것으로 해석하지 않는다. 기존 `llm:stop`은 보존하고 계속 존중한다. 신호는 `claude.overage_seen`과 경고 판정을 남긴다.
- ADR 1032~1045행: 아직 품질 측정이 없는 팔은 최초 표본 수집을 위해 선택 가능하다. 월 크레딧 미달은 각 엔진의 계획 대비 비율로 비교한다. 측정된 품질 실패는 활용 점수 0이며 최소 표본 이후에는 선택하지 않는다. 최근 기록은 에이전트 50건, 창 200개로 한정한다. 감사가 없으면 왜곡률을 만들어내지 않는다. 로컬 전용 과제는 유료 팔로 넘어가지 않는다. 실제 로컬 과제의 골든 검증은 L1 범위다.
- ADR 1801~1805행: O1의 Python/Batch 어댑터와 A1의 PydanticAI는 E1에서 새로 구현하지 않는다. 선택기는 네 엔진을 지원하되 스케줄러는 실행기가 있는 팔만 사용한다. 기본 L2는 OpenRouter와 로컬(sLLM 기존 백엔드 이름 유지), 워크플로우는 OpenRouter·Anthropic API다. 과제마다 팔 하나를 고정하며 실행 중 엔진·모델 대체는 하지 않는다. 교차 감사에는 추출 모델과 다른 벤더의 팔만 둔다.
- ADR 893~894행의 확인 대기 주기는 현재 사용자 지시로 확정됐다: OpenAI 월 $200/28일, Anthropic 월 $200/26일. OpenRouter는 일회성 잔액/2026-11-30 만료다. 날짜는 정보이며 속도 모드를 자동으로 바꾸지 않는다. 지출 계획 계산과 장부 이주는 D5 범위다.
- ADR 946행: Codex는 자동 후보에서 제거한다. 계정 상태 조회도 OpenAI 키 변수를 상속하지 않고 전용 `CODEX_HOME`과 `forced_login_method="chatgpt"`를 쓴다.
- ADR 955~956행: HTTP는 고정 세 API 호스트와 루프백만 허용하며 리다이렉트·환경 프록시를 사용하지 않는다. 엔진별 호스트도 확인한다. 루프백은 로컬 실행과 기존 녹화 응답 시험 서버에 사용한다.

KB 보관 후보: 위의 범위 경계와 미측정 팔의 부트스트랩 결정. 이 Codex 워커에서는 tower 저장 도구를 사용할 수 없어 리드가 검토 후 보관해야 한다.

## 독립 검토 뒤 수정(2026-11-04~05)

- 워크플로우도 기존 `llm:day:<KST 날짜>`의 지출·예약·일일 밸브를 추출과 공유한다. API 호출 직전 명령의 최대 예산을 SQLite `BEGIN IMMEDIATE` 안에서 예약하고, 종료 뒤 실제 비용으로 정산한다. 비용이 없거나 잘못됐거나 호출 뒤 예외가 나면 예약액 전부를 청구한다. 프로세스가 시작되지 않은 경우만 예약을 반환한다. 예약 ID로 중복 정산을 막는다. 강제 종료로 완료를 못 받으면 예약이 남아 추가 지출을 차단한다.
- OpenRouter는 D5 전의 기존 잔액 장부(`llm:or:balance`)와 일일 장부가 기준이다. `credit:openrouter`가 없다고 밸브를 생략하지 않는다. 다른 API와 새 `credit:*` 상태는 `balance`, `budget_usd`, `cycle_spent`, `spent_today`, `reserved`, `cap_today`가 모두 있어야 호출한다. 상태를 추측해 만들거나 운영 장부를 초기화하지 않는다. 엔진별 예약과 잔액은 독립이며 일일 합계 밸브만 공유한다.
- 직접 `kb-agent-run --engine ...`도 선택기와 같은 `engines.available`을 통과하고 예약 시점에 다시 검사한다. 엔진·모델·팔의 정지, `credit:off:*`, pace-off, 잔액·일·주기·목표 상한, 미완성 장부는 명시적 API 호출도 막는다.
- 첫 구현의 API 키 환경 전달은 폐기했다. 로컬 설치 CLI 2.1.318의 `apiKeyHelper` 캐시와 `apiKeySource` 구현을 읽어 확인했다(외부/유료 호출 없음). 키 도우미가 키 파일을 읽어 CLI가 캡처하는 stdout 파이프로만 전달한다. 키 값은 환경·argv·설정 JSON에 없다. 따라서 CLI의 자식은 환경 복사로 키를 얻지 않는다. 서명은 실행 전 `authMethod=api_key, apiKeySource=apiKeyHelper`, 실행 중 `system/init.apiKeySource=apiKeyHelper`로 바뀌었다. CLI 내부 메모리까지 격리하거나 같은 UID의 악의적인 파일 읽기를 막는 보안 경계라는 뜻은 아니다.
- `--setting-sources ''`로 프로젝트 설정을 제외하고 실행별 설정의 `disableAllHooks=true`로 모든 훅을 끈다. 프로젝트 MCP 자동 로딩도 끈다. `--strict-mcp-config`에 넣는 서버는 collector 하나이며, 해당 서버는 환경 허용 목록을 적용하고 인증 환경 변수를 제거한 뒤 `execve`한다. 워크플로우 정의는 기존 작업 디렉터리에서 찾는다. 키 도우미 출력은 인증용 프로세스 간 통신이며 사용자 로그나 보관 스트림이 아니다.
- OpenRouter 오류는 전체 본문·예외를 먼저 마스킹한 뒤 길이를 제한한다. 서버가 이미 축약한 키 접두사(4자 이상)와 오류 끝에서 끊긴 짧은 접두사도 가린다. HTTP 200바이트, JSON 오류 300자 경계에 걸친 키를 시험한다.

## 유료 입장의 불변식(2026-11-05)

유료 실행의 유일한 입장은 `kb.extract.budget.admit(engine, model, role, amount, job=...)`이다. 모델·역할·작업은 빈 값일 수 없다. 예전 `reserve`는 모델을 필수로 요구하고 이 함수로만 전달하는 호환 래퍼다. 예약 토큰 생성자는 `admit` 한 곳에만 있다.

- `P_e`는 엔진 e의 **모든 날짜**의 미정산 예약 합계다. 예약 ID 행이 원본이며, 예전 일일 장부와 크레딧 장부의 예약 인덱스에만 남은 금액도 버리지 않고 보수적으로 더한다. KST 자정이나 월 주기 변경, 감독 프로세스 종료가 예약을 지우지 않는다.
- 입장과 실제 전송 직전에 모두 같은 트랜잭션 정책을 검사한다. 공통 일일 밸브는 `오늘 정산 지출 + 모든 엔진의 P_e + 새 금액 ≤ 밸브`다. 엔진의 잔액은 `P_e + 새 금액 ≤ 남은 잔액`(OpenRouter는 최소 잔액도 보존), 일·주기·목표·pace 상한은 `해당 창의 정산 지출 + P_e + 새 금액 ≤ 상한`이다. 재검사할 자기 예약은 한 번만 센다. 자금을 알 수 없거나 장부·예약·제어를 읽거나 해석할 수 없으면 거부한다.
- 같은 검사에서 엔진·모델·팔·작업의 `llm:off`, `credit:off`, `job:off`, pace-off, 전역 정지, HALT와 `claude_job_gate`를 확인한다. `gate_pass_drop`과 `low_yield`가 쓰는 정확한 모델 키를 검사한다. API 엔진으로 부른 `claude_job_gate`는 읽기 전용 호환 검사이며 구독 카나리아를 실행하지 않는다. 인자 없이 부르는 옛 구독 진입점은 계속 거부한다.
- 토큰은 엔진·모델·역할·작업·금액에 묶인다. L2·함의 판정·교차 감사는 `paid.extract`, 워크플로우·jobs·retro는 `paid.popen`을 거친다. HTTP helper도 토큰을 요구하고 본문의 모델·실제 호스트와 토큰의 엔진을 대조한다. CLI helper는 모델·최대 예산을 대조한다. 요청 구성과 사전 검사 뒤, 실제 HTTP `open`/CLI `Popen` 직전 `before_send`가 제어와 자금을 다시 읽고 토큰을 한 번만 소비한다. 토큰을 복사한 dict, 다른 모델·엔진·작업, 재사용은 거부한다.
- 미전송 토큰만 취소할 수 있으며 취소도 감사 기록을 남긴다. 전송했거나 감독자를 잃은 예약은 시간으로 만료시키지 않는다. 수령한 비용으로 정산하거나, 증빙을 요구하는 `reconcile(id, actual=..., evidence=...)`로 해결한다. 비용을 알 수 없으면 예약액 전부를 청구한다. 감사 행(`llm:reconciled:*`)과 지출·잔액 갱신을 같은 트랜잭션에서 남긴 뒤에만 미정산 행을 없앤다. ID 없는 구형 일일 예약도 자동 삭제하지 않으며 별도 운영 장부 감사 전까지 계속 차단 금액이다. 이 작업은 운영 예약을 해제하거나 조정하지 않는다.
- 명시한 읽기 전용 크레딧 조회와 자격 증명 없는 로컬 추론은 유료 호출이 아니다. API 카나리아도 유료면 같은 토큰이 필요하다. 소비자 Claude/Codex 어댑터의 유료 실행과 구독 카나리아는 전송 코드 자체를 차단한다.
- 시험은 유료 진입점 표, 모든 백엔드 발견, 네트워크 라이브러리·직접 프로세스 실행 발견을 대조한다. 새 백엔드나 raw 전송 경로를 추가하고 표/가드 검증을 빠뜨리면 실패한다. 추가로 실제 사전 검사 중 제어를 바꾸고 L2·support·cross·워크플로우가 호출하지 않는지 검사한다. 이것은 신뢰한 저장소 코드의 구조적 경계이며, 같은 UID가 코드/DB를 악의적으로 바꾸는 상황까지 격리하는 보안 샌드박스는 아니다.
